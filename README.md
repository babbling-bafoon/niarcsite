# NIARC website (w0mcw.com)

Static site for the **North Iowa Amateur Radio Club** (callsign **W0MCW**), Mason City, Iowa.

## Hosting

- Repo: this repository (`babbling-bafoon/niarcsite`)
- Branch `main` deploys via **GitHub Pages** to **https://w0mcw.com** (see `CNAME`)
- Template: [Massively](https://html5up.net/massively) by HTML5 UP (CCA 3.0)

## Editing

Prefer pull requests over direct pushes to `main` so the website committee can review content before it goes live.

Primary content lives in `index.html`. Images are under `images/`; styles and scripts under `assets/`.

Do not invent club contact details (email, Facebook, etc.) — leave placeholders out until a real URL or address is confirmed.
